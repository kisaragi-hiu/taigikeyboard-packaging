* Fedora

** downloading and building locally

download sources into where rpmbuild expects them

#+begin_src sh
spectool -g -R taigikeyboard.spec
#+end_src

install static builddeps, otherwise dynamic builddeps can't be calculated

#+begin_src sh
sudo dnf builddep taigikeyboard.spec
#+end_src

calculate dynamic builddeps

#+begin_src sh
rpmbuild -br taigikeyboard.spec
#+end_src

install dynamic builddeps

#+begin_src sh
sudo dnf builddep ~/rpmbuild/SRPMS/… # rpmbuild will tell you where it is
#+end_src

build both source and binary rpm

#+begin_src sh
rpmbuild -ba taigikeyboard.spec
#+end_src
