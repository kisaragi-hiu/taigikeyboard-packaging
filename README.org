* My TaigiKeyboard packaging for Ubuntu

Initially I followed [[https://optimizedbyotto.com/post/debian-packaging-from-git/][this guide]] for a Git-tracked “Debianized source tree”, but this project is kind of… heavy for that (the pristine tar produced by [[https://manpages.debian.org/testing/git-buildpackage/gbp-buildpackage.1.en.html][gbp]] is almost 900 MiB), and it's also inconvenient for tracking my customized build script that prepares the vendored Cargo dependencies for Launchpad. I've therefore opted to have a dedicated packaging repository instead, since this works better for me as a third party (non-Debian, non-upstream) packager.

** Building

#+begin_src sh
cd ubuntu
make build
#+end_src
