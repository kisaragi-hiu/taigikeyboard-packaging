* My TaigiKeyboard packaging for Ubuntu

** Ubuntu

This is published as a PPA at [[https://launchpad.net/~kisaragi-hiu/+archive/ubuntu/taigikeyboard]].

To install:

#+begin_src sh
sudo add-apt-repository ppa:kisaragi-hiu/taigikeyboard
sudo apt update
#+end_src

Then depending on if you use fcitx5 or ibus:

#+begin_src sh
sudo apt install fcitx5-taigikeyboard
# or
sudo apt install ibus-taigikeyboard
#+end_src

See [[./ubuntu/README.org]] for details on packaging.

** Arch

I added [[https://aur.archlinux.org/pkgbase/taigikeyboard][my AUR package]] as a submodule here for convenience.

To install: use your favorite AUR helper to install =fcitx5-taigikeyboard= or =ibus-taigikeyboard= depending on if you use fcitx5 or ibus.
